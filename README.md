## 📌 Projetos Recentes

🚀 **JobFlow — AI Career Tracker (Em desenvolvimento)**  
Plataforma SaaS para gestão de candidaturas de emprego, permitindo aos utilizadores organizar e acompanhar todo o processo de procura de emprego num único dashboard.

✔️ Autenticação de utilizadores (registo e login)  
✔️ Sistema multi-utilizador com dados isolados por conta  
✔️ Criação e listagem de candidaturas de emprego  
✔️ Dashboard privado por utilizador  
✔️ Integração com Supabase (Auth + PostgreSQL + RLS)  
✔️ Estrutura full-stack moderna com Next.js  

Stack: Next.js, TypeScript, Supabase  

---

📦 **ShareBox**  
Plataforma interna para partilha e gestão segura de ficheiros em ambiente empresarial.  
✔️ Sistema de permissões avançadas por utilizador e grupo  
✔️ Partilha de ficheiros por link/email  
✔️ Registo de atividades (logs) para auditoria  
✔️ Estrutura organizacional baseada em equipas  

Stack: Laravel, PHP, MySQL, HTML, CSS, JavaScript, API REST, Ubuntu Server, VirtualBox   

---

🗂️ **Gestão Documental**  
Sistema de gestão documental para colaboradores, com foco na digitalização de processos internos.  
✔️ Gestão de ausências e justificações  
✔️ Gestão da bolsa de horas  
✔️ Submissão e processamento de documentos sem recurso a papel  
✔️ Dashboards personalizados por tipo de utilizador  
✔️ Registo detalhado de atividades  

Stack: Laravel, PHP, MySQL, HTML, CSS, JavaScript, API REST, Ubuntu Server, VirtualBox    

---

🎓 **InternTrack**  
Plataforma de gestão de estagiários com acompanhamento de todo o ciclo de estágio.  
✔️ Gestão de presenças e validação de documentos  
✔️ Perfis diferenciados (estagiário / administrador)  
✔️ Sistema de aprovação de processos  
✔️ Acompanhamento de progresso do estágio  
✔️ Geração de relatórios personalizados  

Stack: Laravel, PHP, MySQL, HTML, CSS, JavaScript, API REST, Ubuntu Server, VirtualBox
